# 邻里药箱 · 社区常备用品共享借用 / 归还 / 效期提醒与邻里互助

一个基于 **Vue 3 + TypeScript + Pinia + Vue Router + Vite** 的纯前端演示应用，
模拟社区内“未拆封常备用品”的共享全流程：

> 登记 → 志愿者审核发布 → 居民按症状场景申请 → 自取 / 志愿者代送 / 门口无接触交接 → 拍照确认 → 约定归还或补充 → 过期/破损/不适反馈报废，全程留痕。

## 安全边界（产品红线）

- 社区**只做物品流转和风险提醒，不做诊断建议**；共享物品不替代就医。
- **处方药、口服药、拆封药品/耗材、冷链药品不能进入共享**（登记端关键词 + 存放条件 + 开封状态三重校验，志愿者端复核）。
- 每件物品、每次借用都可查看 **来源、效期、包装状态、适用限制** 四要素。
- 包装破损、疑似不适反应可一键反馈；社区工作人员可升级处置并联动下架报废。

## 本地启动

要求 Node.js ≥ 18。

```bash
npm install        # 如遇 npm 缓存目录权限问题，可加 --cache ./.npm-cache
npm run dev        # 默认 http://localhost:5173
```

其他命令：

```bash
npm run build      # vue-tsc 类型检查 + vite 生产构建（输出到 dist/）
npm run preview    # 预览生产构建
npm run typecheck  # 仅做类型检查
```

SSR 页面渲染冒烟（无需浏览器，在 Node 中渲染全部关键页面）：

```bash
node --experimental-strip-types scripts/ssr-smoke.ts
```

数据保存在浏览器 `localStorage`（键前缀 `medkit:`），刷新不丢失。
想恢复演示初始数据：浏览器控制台执行 `localStorage.clear()` 后刷新即可。

## 建议的验证路径

### 1. 居民：按场景借用（默认账号 陈小雨）
1. 打开「互助大厅」，选择场景卡片（如 **孩子夜间发烧**），阅读场景安全提示。
2. 进入「一次性医用外科口罩」详情（有王桂兰、李建国两位邻居同时申请的种子数据），点「我要借用」。
3. 切到共享人 **王桂兰/李建国** →「我共享的」，可见“2 人申请中”；先确认的申请**锁定库存**。

### 2. 登记禁入校验
「登记物品」页分别尝试：
- 品名输入“布洛芬胶囊”→ 提示处方药/口服药禁入；
- 存放条件选“冷藏”→ 提示冷链禁入；
- 取消“整盒未开封”勾选 → 提示拆封物品禁入；
- 有效期选过去日期 → 无法提交。
正常登记一件物品后，志愿者账号的「志愿者中心 → 待审核」会出现该物品。

### 3. 志愿者审核与配送
- 志愿者「林芳」登录：审核新登记物品（通过/驳回，驳回需填原因并通知登记人）。
- 「配送/交接任务」中可看到种子单 **儿童退热贴（r3）已超过约定送达时间**：可催办；
  「无菌纱布块（r10）」是**借用人迟迟未取**：可催办或超时关闭并释放库存。

### 4. 交接拍照与归还/补充
- 待交接订单点「完成交接（拍照）」：必须拍照（内置“模拟拍照”生成带时间戳的凭证图，也可上传本地图片），
  并约定**原物归还 / 补充同款新品 / 耗材赠送**三种方式。
- 共享人在订单上「确认归还入库」（库存自动恢复上架）或「登记补充新品」（登记总量与可借数量同步增加）。

### 5. 撤回与报废联动
- 共享人在物品详情页「撤回共享」：待确认/待交接申请自动取消并释放库存、通知借用人；配送中单通知志愿者停止交接。
- 社工「孙丽」→「社区工作台」：
  - **生理性盐水**已过期：大厅自动隐藏并暂停借用，工作台提示报废；
  - 一键报废后，该物品进行中的申请/配送全部取消并通知各方。

### 6. 包装破损与疑似不适反应
- 借用人在「我的借用」对应订单点「包装破损 / 不适反应反馈」（种子单 r9 卡通创可贴已有一条破损反馈）。
- 志愿者可“开始核实”；社工在工作台结案，疑似不适反应默认**升级处理**，可勾选联动**下架报废**，结果通知反馈人，物品时间线全程留痕。

### 7. 三种视角的差异
- 居民看「我共享的 / 我的借用 / 消息」；志愿者多「志愿者中心」；社工多「社区工作台」（8 项风险指标 + 审计视图）。
- 同一件物品（如 `it14` 报废纱布）在详情页右侧时间线可看到 登记→审核→反馈→报废 的完整串联。

## 自动化验证（已实际执行）

```bash
npm run typecheck                                   # vue-tsc --noEmit，零错误
npm run build                                       # 类型检查 + 生产构建通过
node --experimental-strip-types scripts/ssr-smoke.ts   # 10 个页面 × 3 种身份 SSR 渲染冒烟
npx esbuild scripts/catalog-logic.test.ts --bundle --platform=node \
  --format=esm --alias:@=./src --outfile=/tmp/cl.mjs && node /tmp/cl.mjs   # 禁入校验/效期分级断言
npx esbuild scripts/store-workflow.test.ts --bundle --platform=node \
  --format=esm --alias:@=./src --outfile=/tmp/sw.mjs && node /tmp/sw.mjs   # 全链路状态机断言
```

store 工作流断言覆盖：多人申请库存锁定、超额申请变 lost、取消不扣库存、
逾期关闭释放库存并重新上架、归还入库、补充新品、撤回联动取消、报废联动取消、
过期物品禁止申请、防重复申请。

## 目录结构

```
src/
├─ data/          # 物品目录/场景/禁入规则(catalog)、状态文案(labels)、演示种子数据(seed)
├─ stores/        # Pinia：session / items(核心状态机) / feedback / notifications / 持久化插件
├─ components/    # ItemCard、RequestCard、Apply/Handover/Feedback 弹窗、时间线、拍照、徽章等
├─ pages/         # 大厅、登记、详情、我共享的、我的借用、消息、志愿者中心、社区工作台
├─ utils/         # 效期计算、id
└─ types.ts       # 全领域模型
```
